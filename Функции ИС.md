
# 4.2. Требования к функциям (задачам), выполняемым ИС

**4.2.1.** Для подсистемы управления данными функция загрузки файла должна завершаться сохранением файла в распределённом хранилище с присвоением уникального идентификатора и обеспечением его доступности пользователю; время выполнения зависит от размера файла и пропускной способности канала пользователя, но не должно превышать разумных пределов, определяемых отдельным протоколом нагрузочного тестирования. Функция выгрузки (скачивания) файла должна обеспечивать передачу запрошенного объекта пользователю в исходном виде. Функция кэширования заключается в создании и поддержании актуальности кэш-копий файлов для быстрого просмотра, особенно для изображений и видео.

**4.2.2.** Для подсистемы просмотра и обработки функция быстрого просмотра должна отображать превью изображения, PDF-документа или видео в течение не более двух секунд с момента запроса; функция редактирования текстовых документов должна гарантировать сохранение всех изменений, внесённых пользователем, в хранилище с обеспечением целостности данных.

**4.2.3.** Для подсистемы публикации функция генерации внешней ссылки должна создавать уникальную ссылку для доступа к файлу с возможностью настройки срока действия и опциональной защиты паролем.
